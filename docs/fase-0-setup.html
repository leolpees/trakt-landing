Sem isso, nada do resto funciona. Complete os 6 passos abaixo — leva 1 a 2 horas no total.

Progresso 0 / 6 concluídos
Passo 1
Criar conta de desenvolvedor Meta
Acesse developers.facebook.com com sua conta Facebook
▾
  • 1Acesse o link abaixo com a sua conta Facebook pessoal (precisa ser a conta vinculada ao seu Business Manager)
  • 2Clique em "Get Started" se for a primeira vez, ou confirme que já tem acesso de desenvolvedor ativo
  • 3Aceite os Termos de Serviço da plataforma Meta for Developers
↗ Abrir developers.facebook.com
ℹ

Se você já usa o Meta Business Suite no dia a dia, a conta de desenvolvedor usa o mesmo login. Não cria uma conta separada.

Passo 2
Criar o App Meta (tipo Business)
Um único app para todos os clientes do Raio
▾
  • 1No painel do desenvolvedor, clique em "My Apps" → "Create App"
  • 2Selecione o tipo: "Business" (não "Consumer" ou "Gaming")
  • 3Preencha o nome do app: "Raio" (ou qualquer nome — pode mudar depois)
  • 4Informe seu e-mail de contato e selecione seu Business Portfolio (Business Manager)
  • 5Clique em "Create App"
⚠

Selecione tipo Business obrigatoriamente. O tipo errado impede o acesso às APIs do Instagram e WhatsApp.

ℹ

Você não cria um app por cliente. Este único app vai atender todos os clientes do Raio via OAuth.

Passo 3
Adicionar produtos ao app
Instagram + WhatsApp — ambos são obrigatórios
▾
  • 1Dentro do app criado, vá em "Add Products" no menu lateral
  • 2Clique em "Set Up" ao lado de Instagram
  • 3Clique em "Set Up" ao lado de WhatsApp
  • 4Confirme que ambos aparecem no menu lateral esquerdo do app
Permissões que você vai precisar (configurar depois)
instagram_manage_messages instagram_basic instagram_manage_insights whatsapp_business_messaging whatsapp_business_management ads_read
Passo 4
Configurar conta de teste do Instagram Business
Necessário para testar o webhook antes de ir para produção
▾
  • 1No menu do app, vá em Instagram → Basic Display → Create New Test User
  • 2Ou: conecte sua conta Instagram Business real em Instagram → API Setup clicando em "Add Instagram Test Account"
  • 3A conta Instagram precisa ser do tipo Business ou Creator (não conta pessoal)
  • 4Autorize o app a acessar a conta quando solicitado
ℹ

Em modo desenvolvimento, o app só funciona com até 5 contas de teste. Para contas de terceiros (clientes do Raio), você precisará submeter o app para revisão da Meta — isso vem na Fase 7.

Passo 5
Configurar número de teste do WhatsApp Business
A Meta fornece um número gratuito para desenvolvimento
▾
  • 1No menu do app, vá em WhatsApp → API Setup
  • 2A Meta já cria automaticamente um número de teste gratuito — você vai ver ele na seção "From"
  • 3Em "To", adicione seu número pessoal como destinatário de teste (pode enviar até 5 números para teste gratuito)
  • 4Clique em "Send Message" para verificar que o número está funcionando
  • 5Anote o Phone Number ID e o WhatsApp Business Account ID (WABA ID) que aparecem nessa tela
⚠

O número de teste tem limite de envios. Para produção você vai precisar conectar um número real via WhatsApp Business Platform.

Passo 6
Anotar as credenciais
Você vai precisar delas para cada linha de código daqui para frente
▾
  • 1App ID e App Secret → Menu do app → Settings → Basic
  • 2Phone Number ID → WhatsApp → API Setup → campo "Phone number ID"
  • 3WABA ID → WhatsApp → API Setup → campo "WhatsApp Business Account ID"
✓ Salvo localmente (só no seu navegador)
⚠

Nunca commite o App Secret no Git. Sempre use variáveis de ambiente (.env + .gitignore).

# .env — nunca commitar este arquivo
META_APP_ID=seu_app_id_aqui
META_APP_SECRET=seu_app_secret_aqui
WA_PHONE_NUMBER_ID=seu_phone_number_id
WA_WABA_ID=seu_waba_id
VERIFY_TOKEN=qualquer_string_secreta_sua

Fase 0 concluída

App Meta configurado. Você está pronto para a Fase 1 — escrever o primeiro webhook.

A seguir — Fase 1

Primeiro Webhook

Com o app configurado, você vai subir um servidor Node.js em menos de 30 linhas e receber a primeira DM em tempo real no console.

npm init -y && npm install express dotenv

# server.js rodando em localhost:3000
app.get('/webhook', verify_token_check);
app.post('/webhook', (req, res) => {
  console.log('DM recebida:', req.body);
  res.sendStatus(200);
});
