Jornada do cliente
Como um novo cliente conecta o Instagram
Do primeiro acesso à plataforma até o webhook escutando as DMs dele automaticamente.
1

Cliente cria conta no Raio

E-mail e senha. Nenhuma configuração técnica necessária — o Raio cuida de tudo nos bastidores.

2

Clica em "Conectar Instagram"

O Raio redireciona para a tela de autorização da Meta. O cliente não vê código, não vê API — só uma tela familiar do Instagram/Facebook.

3

Cliente autoriza as permissões

A Meta mostra quais permissões o app vai usar: ler mensagens, ver insights. O cliente clica em "Permitir".

4

Meta redireciona para /auth/callback

O servidor recebe um código temporário, troca por um token de acesso permanente, e salva no banco vinculado à conta do cliente.

5

Dashboard ativo — DMs chegando em tempo real

A partir desse momento, toda DM recebida no Instagram do cliente dispara o webhook e aparece no painel com origem, intenção e urgência.

Autorização
O que acontece quando o cliente clica em "Permitir"
O fluxo técnico do OAuth em linguagem simples.
🔗
Raio redireciona o cliente para a Meta Com o App ID do seu app. A Meta sabe que é o Raio pedindo acesso.
✅
Cliente clica em "Permitir" na tela da Meta A Meta gera um código temporário (válido por minutos).
🔄
Meta chama /auth/callback?code=XXXXX Seu servidor recebe o código e troca por um token de acesso real chamando a API da Meta.
💾
Token salvo no banco vinculado ao cliente A partir de agora, o webhook recebe as DMs dessa conta e o servidor sabe a quem pertencem pelo recipient.id.
